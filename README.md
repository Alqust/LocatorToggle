# LocatorToggle

Плагин для **Folia / Paper 26.3**, который позволяет каждому игроку самому включать и выключать Locator Bar.

## Как работает

- Двое игроков видят друг друга на локаторе, **только если локатор включён у обоих**.
- Если игрок выключил локатор — его никто не видит, и он сам никого не видит (вместо локатора обычная полоса опыта).
- Игрок в режиме наблюдателя не виден на локаторе и сам его не видит. После выхода из наблюдателя локатор возвращается (если был включён).
- Ванильные правила скрытия сохраняются: присед, невидимость, тыква или голова моба на голове.
- Выбор игрока хранится в его данных и сохраняется после перезахода и рестарта.

### Почему на Folia нужен отдельный механизм

В Folia ванильный менеджер локатора (`ServerWaypointManager`) отключён — сервер не отправляет игрокам точки, и локатора нет ни у кого.
На Folia плагин сам рассылает точки локатора: каждый игрок в своём потоке региона записывает свою позицию и получает точки остальных — без обращения к чужим сущностям из другого потока.
На обычном Paper используется ванильный механизм, а плагин только управляет атрибутами `waypoint_transmit_range` / `waypoint_receive_range`.

## Команды

| Команда | Что делает |
|---|---|
| `/locator` | Открыть меню |
| `/locator on` / `off` / `toggle` | Включить / выключить / переключить без меню |

Синонимы: `/lb`, `/locatorbar`. Право: `locatortoggle.use` (по умолчанию есть у всех).

## Настройки

`config.yml`:

```yaml
# Включён ли локатор у игрока, который ещё ни разу его не переключал
default-enabled: true
```

Игровое правило `locator_bar` должно быть включено.

## Сборка

Нужен JDK 25.

```bash
./gradlew build
```

Готовый файл: `build/libs/LocatorToggle-1.0.0.jar`.
